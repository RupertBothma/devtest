# DevOps Engineer Assessment

## Overview

This assessment evaluates your ability to containerize applications, implement CI/CD pipelines, and deploy to Kubernetes. You are free to make reasonable assumptions and choose your own tools and conventions where details are not specified. Part of the assessment is how you justify your decisions.

**Deliverables:** GitHub repository with complete source code and documentation

## Tasks

### Task 1: Dockerize a Python Application

Create a Docker container for a Python application.

### Task 2: GitHub Actions CI/CD Pipeline

Create a GitHub Actions workflow that automates build, test, and deployment processes.

### Task 3: Helm Chart for Kubernetes Deployment

Create a Helm chart to deploy the application to Kubernetes. Include all the basics you think will be required to serve the application.

## Submission

Provide a GitHub repository containing all code and a README.md that includes setup instructions, decisions, and deployment steps.
